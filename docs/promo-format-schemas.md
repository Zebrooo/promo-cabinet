# Схемы промо-форматов

Справочник по полям каждого из 8 типов промо (`src/lib/schema.ts`, `SCHEMA_BY_FORMAT`/`CONTENT_KEYS_BY_FORMAT`). Документ описывает форму zod-схемы «как есть»: тип поля, обязательность на уровне схемы и русское описание назначения.

## Общие поля (serving) — одинаковы для всех форматов

Слой 1 схемы — таргетинг/расписание/частота показов. Именно эти поля BFF использует для отбора кандидата до рендера контента.

| Поле | Тип | Обязательность | Описание |
|---|---|---|---|
| `id` | строка | обязательно | Уникальный идентификатор промо |
| `name` | строка | обязательно | Название промо для админки (не показывается юзеру) |
| `title` | строка | обязательно | Заголовок промо — обязателен для всех форматов, часть контракта BFF |
| `startsAt` | строка (ISO datetime) | обязательно | Дата и время начала показа |
| `endsAt` | строка (ISO datetime) | обязательно | Дата и время окончания показа |
| `schedule` | объект (см. под-поля ниже) | опционально | Расписание показов (dayparting) поверх окна дат: дни недели + часы МСК; отсутствие поля = 24/7 |
| `schedule.daysOfWeek` | массив<число> | обязательно | Дни недели показа, ISO-нумерация (1=Пн … 7=Вс); непустой список без дублей |
| `schedule.hourStart` | число | обязательно | Час начала показов (0–23, включительно, МСК) |
| `schedule.hourEnd` | число | обязательно | Час окончания показов (1–24, ИСКЛЮЧАЮЩАЯ граница; 24 = до полуночи, МСК) |
| `targeting` | объект (см. под-поля ниже) | обязательно | Таргетинг аудитории показа |
| `targeting.minAge` | число | опционально | Минимальный возраст юзера |
| `targeting.maxAge` | число | опционально | Максимальный возраст юзера |
| `targeting.regions` | массив<строка> | опционально | Список регионов показа (пусто = без ограничения) |
| `targeting.subscriptionLevels` | массив<enum(none / plus / premium)> | опционально | Уровни подписки юзера, которым показывается промо |
| `targeting.os` | массив<enum(ios / android)> | опционально | — |
| `targeting.environments` | массив<enum(browser / telegram / pwa / app)> | опционально | — |
| `targeting.deviceBrands` | массив<enum(iphone / android-flagship / android-other)> | опционально | — |
| `targeting.geoSegments` | массив<enum(local / tourist / other)> | опционально | IP-гео: сегменты показа — local (Абхазия) / tourist (Россия) / other (пусто = без гео-ограничения); если гео не определилось (VPN), промо с правилом не показывается |
| `targeting.geoCities` | массив<строка> | опционально | IP-гео: города-слаги, где юзер находится СЕЙЧАС (пусто = любой город; в отличие от targeting.regions — города из профиля) |
| `targeting.visitorClass` | enum(newcomer / regular) | опционально | Профиль визита: newcomer (молодой аккаунт/браузер) или regular (заходит часто); нет поля = любой посетитель; без сигнала промо не показывается |
| `targeting.newcomerMaxAgeDays` | число | опционально | Порог «новичка»: аккаунт/браузер моложе N дней (1–365; пусто = дефолт BFF 7); имеет смысл только при visitorClass=newcomer |
| `targeting.regularMinVisitDays` | число | опционально | Порог «постоянного»: не менее M разных дней с визитами за месяц (1–30; пусто = дефолт BFF 5); имеет смысл только при visitorClass=regular |
| `targeting.search` | объект (см. под-поля ниже) | опционально | Таргетинг по истории запросов из search_queries (пустые фразы и разделы = фильтр выключен) |
| `targeting.search.terms` | массив<строка> | опционально | Поисковые фразы для сопоставления (до 20 фраз, 2–80 символов каждая; после нормализации остаётся минимум 2 буквы или цифры) |
| `targeting.search.sections` | массив<строка> | опционально | Разделы, в которых юзер выполнял поиск (до 20 значений) |
| `targeting.search.match` | enum(any / all) | опционально | Режим совпадения поисковых фраз: хотя бы одна (any) или все (all) |
| `targeting.search.lookbackDays` | число | опционально | Глубина истории поиска: от 1 до 30 дней (по умолчанию 30) |
| `targeting.purchases` | объект (см. под-поля ниже) | опционально | — |
| `targeting.purchases.purchased` | булево | опционально | — |
| `targeting.purchases.minTotalKopecks` | число | опционально | — |
| `targeting.purchases.maxTotalKopecks` | число | опционально | — |
| `targeting.purchases.minCount` | число | опционально | — |
| `targeting.purchases.maxCount` | число | опционально | — |
| `targeting.purchases.packTypes` | массив<enum(bump / premium / vip)> | опционально | — |
| `targeting.purchases.lookbackDays` | число | опционально | — |
| `targeting.balance` | объект (см. под-поля ниже) | опционально | — |
| `targeting.balance.currentAbove` | число | опционально | — |
| `targeting.balance.currentBelow` | число | опционально | — |
| `targeting.balance.movementAbove` | число | опционально | — |
| `targeting.balance.movementBelow` | число | опционально | — |
| `targeting.balance.movementLookbackDays` | число | опционально | — |
| `targeting.listings` | объект (см. под-поля ниже) | опционально | — |
| `targeting.listings.categories` | массив<строка> | опционально | — |
| `targeting.listings.categoriesMatch` | enum(any / all) | опционально | — |
| `targeting.listings.activeCategories` | массив<строка> | опционально | — |
| `targeting.listings.hasUnpromotedActive` | булево | опционально | — |
| `targeting.listings.inactiveDays` | число | опционально | — |
| `maxImpressionsPerUser` | число | опционально | Лимит показов на юзера (пусто = без лимита) |
| `cooldownHours` | число | обязательно | Пауза между повторными показами одному юзеру, часов |
| `afterPromoId` | строка | опционально | Показывать только после того, как юзер видел указанное промо (id предшественника в цепочке) |
| `audience` | enum(all / authenticated / anonymous) | опционально | Аудитория: все / только авторизованные / только анонимные |
| `sections` | массив<строка> | опционально | Список разделов сайта, где показывается промо |
| `categories` | массив<строка> | опционально | Список категорий, где показывается промо |
| `sellerStatus` | enum(seller / buyer) | опционально | Показывать только продавцам или только покупателям |
| `entrySources` | массив<enum(direct / search / telegram / other)> | опционально | Классы источника захода текущей сессии — direct / search / telegram / other (по referrer/utm, кука 30 минут; пусто = любой источник) |
| `deviceTarget` | enum(desktop / touch / both) | опционально | Устройства показа: десктоп / тач / оба |

## DivKit — JSON-верстка

> `divkitUrl` и `divkitJson` оба опциональны в схеме (storage-контракт), но на форме обязателен хотя бы один из них: `divkitUrl || divkitJson`.

| Поле | Тип | Обязательность | Описание |
|---|---|---|---|
| `divkitUrl` | строка (URL) | опционально | URL на JSON-вёрстку DivKit в S3 (production-вариант) |
| `divkitJson` | произвольное значение (unknown) | опционально | Инлайн JSON-вёрстка DivKit для превью до сохранения (в проде не хранится) |
