# Схемы промо-форматов

Справочник по полям каждого из 8 типов промо (`src/lib/schema.ts`, `SCHEMA_BY_FORMAT`/`CONTENT_KEYS_BY_FORMAT`). Документ описывает форму zod-схемы «как есть»: тип поля, обязательность на уровне схемы и русское описание назначения.

## Общие поля (serving) — одинаковы для всех форматов

Слой 1 схемы — таргетинг/расписание/частота показов. Именно эти поля BFF использует для отбора кандидата до рендера контента.

| Поле | Тип | Обязательность | Описание |
|---|---|---|---|
| `id` | строка | обязательно | Уникальный идентификатор промо |
| `name` | строка | обязательно | Название промо для админки (не показывается юзеру) |
| `title` | строка | обязательно | Заголовок промо — обязателен для всех форматов, часть контракта BFF |
| `startsAt` | строка (ISO datetime) | обязательно | Дата и время начала показа |
| `endsAt` | строка (ISO datetime) | обязательно | Дата и время окончания показа |
| `targeting` | объект (см. под-поля ниже) | обязательно | Таргетинг аудитории показа |
| `targeting.minAge` | число | опционально | Минимальный возраст юзера |
| `targeting.maxAge` | число | опционально | Максимальный возраст юзера |
| `targeting.regions` | массив<строка> | опционально | Список регионов показа (пусто = без ограничения) |
| `targeting.subscriptionLevels` | массив<enum(none / plus / premium)> | опционально | Уровни подписки юзера, которым показывается промо |
| `maxImpressionsPerUser` | число | опционально | Лимит показов на юзера (пусто = без лимита) |
| `cooldownHours` | число | обязательно | Пауза между повторными показами одному юзеру, часов |
| `afterPromoId` | строка | опционально | Показывать только после того, как юзер видел указанное промо (id предшественника в цепочке) |
| `audience` | enum(all / authenticated / anonymous) | опционально | Аудитория: все / только авторизованные / только анонимные |
| `sections` | массив<строка> | опционально | Список разделов сайта, где показывается промо |
| `categories` | массив<строка> | опционально | Список категорий, где показывается промо |
| `sellerStatus` | enum(seller / buyer) | опционально | Показывать только продавцам или только покупателям |
| `deviceTarget` | enum(desktop / touch / both) | опционально | Устройства показа: десктоп / тач / оба |

## DivKit — JSON-верстка

> `divkitUrl` и `divkitJson` оба опциональны в схеме (storage-контракт), но на форме обязателен хотя бы один из них: `divkitUrl || divkitJson`.

| Поле | Тип | Обязательность | Описание |
|---|---|---|---|
| `divkitUrl` | строка (URL) | опционально | URL на JSON-вёрстку DivKit в S3 (production-вариант) |
| `divkitJson` | произвольное значение (unknown) | опционально | Инлайн JSON-вёрстка DivKit для превью до сохранения (в проде не хранится) |

## Custom — Host-компонент
